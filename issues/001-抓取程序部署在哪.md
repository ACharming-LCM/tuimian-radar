# 001 抓取程序部署在哪

- **提出**：A  2026-10-16 21:20
- **状态**：open
- **阻塞谁**：A（决定每天的定时任务怎么写）、以及"每天更新"这个核心卖点能不能兑现
- **背景**：

  实测 `www.grs.zju.edu.cn` 的 DNS 解析结果是 `10.202.73.10` —— **内网地址**，
  而且 **443（HTTPS）拒绝连接，只有 80（HTTP）通**。`physics.zju.edu.cn` 和 `mse.zju.edu.cn` 目前公网可访问。

  意思是：浙大研究生招生网这类站点，**绝大多数公网云主机根本连不上**。
  这不是爬虫技术问题，是网络拓扑问题。放到阿里云/腾讯云上，这部分站点会全量抓不到，
  而"漏掉一条报名通知"就足以让用户不再信任这个产品。

- **选项**：
  1. **跑在校内**（实验室服务器 / 自己的电脑 / 课题组机器）。零成本、能抓到内网站点，
     但依赖个人机器在线，比赛现场演示没问题，长期运营不稳。
  2. **教育网 VPS**（如 CERNET 接入的云主机）。稳，但要钱、要申请。
  3. **双通道**：公网站点走云主机，内网站点走校内机器，两边结果合并。
     架构最正确，但工作量最大，四天做不完。
- **需要**：三人一起拍板。**比赛阶段建议选 1**，把 2/3 写进 PPT 的"下一步"。
