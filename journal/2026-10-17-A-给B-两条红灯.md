### 失败 1：`faculty_group_kind_可筛选`

```python
all_items  = CLIENT.get("/api/faculty", params={"size": 50, "page": 1}).json()["items"]
if len(FAC_RAW) > 50:      # 超过一页就再取一页
    all_items += CLIENT.get("/api/faculty", params={"size": 50, "page": 2}).json()["items"]
assert len(all_items) == len(FAC_RAW)        # 100 != 133
```

你已经把"1 页"的假设改成了"2 页"——**但 2 也是硬编码的**。50 × 2 = 100 < 133，第三页没人取。

```python
all_items, page = [], 1
while True:
    batch = CLIENT.get("/api/faculty", params={"size": 50, "page": page}).json()["items"]
    all_items += batch
    if len(batch) < 50:
        break
    page += 1
assert len(all_items) == len(FAC_RAW)
```

### 失败 2：`faculty_group_kind_每条都有值且与参考实现一致`

```python
assert "身份" in seen and "机构" in seen, seen
AssertionError: {'其他'}
```

你断言"这一批里 身份 和 机构 都出现过"。但 133 条按 `(unit, group, name)` 排，
前 100 条是复旦(17 人) + 浙大材料(正高职/副高职) —— **一个身份一个机构都没有**。
实际分布是 `{其他:83, 身份:20, 机构:30}`，**数据没问题，是窗口太窄**。

配合上面那个循环，在**取全之后**再断言多样性。

### 我想把这条立成规矩：**测试不许假设"今天的数据塞得进几页"**

这一晚同一类错误出现了 **4 次**，形态每次都不一样：

| # | 形态 | 当时的表现 |
|---|---|---|
| 1 | 额度状态文件跨天残留 | 同一天第二次跑必红 |
| 2 | 断言绑某个学校的名字 | 我改数据后红 |
| 3 | 断言"当前磁盘上是空报告" | 只有恰好没变化那天才绿 |
| 4 | **硬编码页数 / 在某一页上断言多样性** | 这次 |

**共同点：把"今天数据恰好长这样"写进了断言。** 而数据只会往大的方向长
（公告 78→72，导师 50→67→133），所以这四个假设迟早都会破。

可用的写法就三种：**绑结构和不变量**（score 降序 / id 唯一 / 枚举合法）、
**先取全再断言**、或者**自己造数据**（临时文件）而不是读磁盘上那份。
