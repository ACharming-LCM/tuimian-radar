## 一、**变了什么**（这四条不并进去，你会白干）

### 1. 【会作废你的截图】`relevance` 判据收紧了

数据层把宣传材料（宣传册 / 风采合集 / 宣讲会 / 直播 / 招生简介 / 招募）**封顶到 1 档**：

**直接后果：公告列表的顺序变了。**
原来排最前面那批「学院风采合集…研究生招生宣传册」「研究生招生直播宣讲会」会往后掉。

### 2. `?meta=1` 新增 `data_state`（后端加的，契约 §15.3）

```json
{"loaded": 196, "matched": 0, "skipped_lines": 0,
 "source_empty": false, "empty_reason": "no_match", "note": "…"}
```

`empty_reason` ∈ `null`（有结果）/ `no_match`（你筛太窄）/ `source_empty`（数据还没进来）。

⛔ **`source_empty` 要显示「数据还没加载」，绝不许显示成"没有符合条件的公告"** ——
前者是系统的事，后者是用户的事。这两个 `total:0` 长得一样但意思相反。

### 3. 套磁信引文**会变少**（后端加的，契约 §3）

纯表格式公告**不再引表格行**了，只引标题 / 材料 / 截止日；响应多一个
`quotes_dropped: [{source, reason}]`（**只有 source 和 reason，没有原文**）。

界面上如果有个"引文 N 条"的数字，它会变小 —— **那是变诚实，不是坏了。别当 bug 修。**
`quotes_dropped` 有内容时，可以给一句人话（比如"有 2 条候选引文判不准，已丢弃"），
但**不要把被丢的原文显示出来**（那等于换个字段名继续显示）。

### 4. `/api/health` 可上自检页：`data.load_state`（`ok`/`degraded`/`empty`）+ `state.ok`

`degraded` = 数据源里有坏行被跳过（少了数据但服务可用）；`empty` = 0 条。

## 二、四环

### 环 6：接住上面这四条

不是"加个字段显示"，要**在判断逻辑里用上**：
- `data_state` 和 `field_state` 是**两个不同的"不知道"**，**不许混成一句「暂无数据」**
  - `source_empty` → 系统级：「数据还没加载」
  - `deadline: unknown` → 条目级：「未能读取截止日，请点原文核对」
  - `quotes_dropped` 非空 → 功能级：「有候选引文判不准，已丢弃」
- **硬约束**：`field_state` 整个缺失时按 `unknown` 措辞，
  **绝不许显示成"没有截止日" / "暂无" / "——" / 干脆不显示**。
  **不显示最危险**：用户会以为"这条没有截止日"，于是**不去看原文**。

### 环 7：契约漂移面板（欠很久了，`docs/HANDOFF-C.md` §6.4）

逐页比对 `contracts/api.md` 白名单：
- 渲染了但契约没有的字段 → **报警**（可能是泄漏了内部字段，比如 `relevance`）
- 契约有但页面从没用到 → 列出来（可能是我们漏做了一个信息）

**宿主已经有了**（论坛页 `forum.js` 那块「前台字段自检」）。
`api.md` 刚加了 §15，白名单变长了，这个面板正好能发现我们漏接了什么。

### 环 8：降级路径要说实话

接口不通 → 退到 fixtures。**降级时必须明确标出来**：哪些功能不能用
（今日更新的"过去 N 天"、论坛现场发帖）。
判据：**用户能一眼看出"现在是样例数据，不是实时"**，而不是以为数据就长这样。

### 环 9：把五环 + 上面三条变成**一条命令能跑**的断言

现在四态靠 CDP 截图人工看。**截图进不了提交前检查。**
输出要"哪一页、哪种畸形、什么表现"，不是只给红绿。
