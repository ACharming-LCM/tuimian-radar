### 三个设计决定（都写进契约了，理由不只在这里）

**① `GET /api/push/preview` 只读、`POST` 才记录。**

预览是"看一眼"。如果看一眼就消耗掉一条推送，用户刷新一次页面就会看到
"你已经收到过了" —— **那是把展示行为当成消费行为**。

所以 GET 幂等（刷新十次一模一样），POST 是"我接收这批"，之后那些事件进
`suppressed` 且 `reason=duplicate`。

这个区别演示时正好能讲一分钟：**"预览不消费、接收才消费"**。

**② 提醒 T-7/T-3/T-1 是窗口，不是"精确第 N 天"。**

推送的触发点是"用户打开看"，不是定时器。用户可能第 8 天才打开，
精确制会让他 **4 天截止时什么提醒都收不到** —— 而那正是最该提醒的时候。

所以 `days_left ≤ 7` 就挂 T-7（取最紧一档：4 天 → T-7，2 天 → T-3）。

**③ 免费层给前 3 条，不是 0 条。**

一个只有付费才能看到的推送，用户在购买前无法判断它值不值 ——
**那不是付费墙，是赌博**。给"看得见"的一部分，但截断必须说出来
（`tally.truncated_reason="free"`）。

### 怎么验的

**反向验证（这是这一场最花时间的部分，也是最值的）。**
把实现故意改坏，看门禁红不红：

| 改坏什么 | 期望红的门禁 | 实测 |
|---|---|---|
| `UNKNOWN_DEADLINE_TEXT` → 「暂无截止日」 | `unknown_不许被当成_absent` | ✓ 红在 `('暂无', '暂无截止日')` |
| `push_id` 掺时间戳 | `重复事件不重复推送` | ✓ 红在"两次 GET 的 id 不一致" |
| 抹掉 `url` | `每条推送必含原文链接` | ✓ 红在 `('缺原文链接', 'e_url_0')` |
| 提醒改成"精确第 N 天" | `提醒只对_found_且窗口取最紧一档` | ✓ 红在 4 天拿不到 T-7 |
| 三种空原因写成同一句 | `空的原因四态分得开` | ✓ 红在"三句话不该有两句一样" |
| `PUSH_FREE_LIMIT` → 0 | `免费层给前三条且说清截断` | ✓ 红 |
| 多/少一个顶层键 | `预览形状与_fixture_一致` | ✓ 两个方向都红 |

**抓到一条我自己的自证**：`push_免费层给前三条` 第一版写的是
`assert len(items) == config.PUSH_FREE_LIMIT` —— 期望值来自实现用的同一个常量。
把常量改成 0，断言跟着变成 0，**照样绿**。

这和我今天上午删掉的 `LISTING_SORT_FIXTURE_STALE` 是**同一个病**：
"期望值来自被测代码自己"。改成写死 3（契约规定的数）之后才真的能红。

**边界实测**：`limit=0/9999/abc`、`source=xxx`、`limit=abc` 的 4xx 是 JSON 不是 HTML。

**隔离实测**：跑完三条命令，`server/var/state.json` 的 mtime 和大小**一个字节没变**
（1097 字节 / 8:45:11）。`demo_push.py` 用 `:memory:` + 注入的样例事件。

### 我自己踩的坑（记下来）

1. **§7.9 又犯两次**：`profile.py` 和 `push.py` 里各有一处字符串内部用了 ASCII `"` 当中文引号 →
   `SyntaxError: Perhaps you forgot a comma?`。**一字不差地复现了交接文档那条记录。**

2. **第一版 `push.py` 写废了**：`build_item` 里留了一个语法错误的占位函数，
   还有一个拼错的变量 `win_dow`。整份重写才干净。**教训：一次写太长容易出残骸，
   分段写 + 每段 `ast.parse`。**

3. **fixture 不能手写。** 我一开始想手写三份 fixture 让 C 快点开工，
   写到一半发现 `deadline_display` 对 `found` 返回的 `text` 是**日期本身**
   而不是"截止 2026-10-21（还剩 4 天）"—— 手写的一定会和实现漂。
   改成**先写实现、再用真实输出切 fixture**，只多花二十分钟，少一次返工。

4. **`limit=0` 被 `or` 吃成了默认值。** `int(limit or MAX)` 里 `0` 是 falsy，
   于是"要 0 条"被静默当成"没传"。改成 `if limit is None`。

5. **`source=xxx` 时我把 `JSONResponse` 又包了一层 `_json()`** →
   `TypeError: Object of type JSONResponse is not JSON serializable`。
   修法是让 `_push_preview` 直接返回响应对象，路由不再包。
