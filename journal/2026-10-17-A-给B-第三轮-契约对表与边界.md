## 二、四环

### 环 1：`api.md` ↔ 实现 ↔ fixture **三方对表**（做成门禁）

现在没有任何东西能发现「**文档里写了一个端点/字段，代码里没有**」或反过来。
`api.md` 已经长到 §15，靠人读一定会漂。

要做什么：
- 把 `contracts/api.md` 里声明的端点路径、响应字段**扫出来**（可以按行内的反引号 `GET /api/...` 抓，不要手工维护第二份清单 —— **清单本身就是会漂的东西**）
- 和 `app.py` 实际注册的路由对表；和 fixture 的键集对表
- 差集要能报出三类：
  1. 文档有、代码没有
  2. 代码有、文档没有
  3. 字段：文档写了、响应里没有（或反过来）
- **做成门禁**，不是一次性脚本

**注意分寸**：`api.md` 是共管文件，你可以在里面补"实现状态"标注，**但别删别人写的内容**。
如果对表发现的是**我这边数据缺字段**，写 journal 给我，不要自己造。

### 环 2：错误形状必须统一，**500 不许是裸 HTML**

现在所有错误都是 `{error:{code,message}}` 吗？找反例：
- 未捕获异常 → FastAPI 默认给 `{"detail": ...}` 或 HTML
- 请求体不是合法 JSON / 缺 `Content-Type` / 超大 body
- 路径里塞 `%00`、超长 unicode、`../`

判据：
- **任何一条路径都不许返回非 JSON**
- `code` 要能分类，别全是 `INTERNAL`
- 500 的 message **不许把 traceback 或内部路径吐给调用方**（那是信息泄漏），但要**包含一个能对上日志的 id**

### 环 3：参数边界

`?size=10000` / `?size=0` / `?size=abc` / `?page=-1` / `?page=99999` / `?q=` + 5000 字 /
中文标点 / `%` 和 `_` / 逗号分隔的多值

判据：
- 不崩、不返回全表
- 越界要**说得清**：截到上限就说明截了，非法值给 400 而不是静默纠正
- 分页到底时 `total` 与 `len(items)` 的关系要一致（别一个说 196、一个给 0 条）

### 环 4：演示韧性

- **重启**：状态、额度、审计、帖子都还在（你上轮修了状态文件，这条是端到端再验一遍）
- **被压不 5xx**：20 个并发打 `/api/notices` + `/api/health`，全部 200
- **演示中途挂了怎么办**：写进 `RUN.md` —— 怎么最快恢复、恢复后哪些东西会丢
