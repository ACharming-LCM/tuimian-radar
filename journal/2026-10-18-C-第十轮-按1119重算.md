### 四、真 bug：`common.js` 在说一句文档明令禁止的话

`docs/DATA-NUMBERS.md` §一 写着：

> **⚠️ 别说「覆盖 37 所学校」。** 配置了 37 个站点，其中 5 个产出 0 条。

而页头**真的在说**「1119 条公告 · 数据更新于 1.6 小时前 · **覆盖 37 所学校**」。
来源是 `common.js:454`：

```js
if (n(t.schools) !== null) bits.push('覆盖 <strong>' + t.schools + '</strong> 所学校');
```

`t` 是 `freshness.totals`，而 `totals.schools` 到底了是**站点数**：

```
/api/freshness → schools 数组 37 个条目（每个是 (school, unit)）
                 distinct school = 29
```

**37 是"37 个栏目"，29 才是"29 所学校"。** 两个概念被一个字段名合并了，
于是文档禁止的那句话从代码里自己长了出来 —— 而写文档的人（我）根本不知道它在界面上。

**修法**（只改一处实现，三个页面同时生效）：

- `normFreshness` 里现算 `site_count`（条目数）和 `school_count`（按 `school` 去重）；
- `freshnessBarHTML` 三层取值兜底（防 `live.js` 重渲染时拿到的是原始对象），输出
  「**29 所学校 · 配置 37 个站点**」；
- `daily.js` 同一处：「37 所学校全部抓到了」→「37 个站点全部抓到了（29 所学校）」；
- `freshnessIssuesHTML` 的「N / 37 **所**学校有情况」→「N / 37 **个站点**有情况」。

**验收**（CDP 实测，1440 与 375）：

```
match / notices / daily 三页 fbar：
  「1119 条公告 · 数据更新于 1.6 小时前 · 29 所学校 · 配置 37 个站点」
全站「覆盖 N 所学校」出现次数：0
```

> 教训和这一晚反复出现的那个形态一样：**不是代码写错了，是一个字段名的含义被默认了。**
> `totals.schools` 看着像"学校数"，实际是条目数。没人去数一遍。

## 七、收尾（2026-10-18 02:10）：把「我的举报」的 404 残留剔掉

统筹给的最后一个任务，10 分钟。做完这一轮就收工。

### 起因

`forum.html` 每次加载都会在控制台留 **2 个 404**。查下去是 `localStorage` 的
`tuimian_reported_ids` 里存着 `p_20261017_0003` / `_0004` —— 那两条帖已经换掉一批种子，
逐条查 `GET /api/posts/{id}/moderation` 就 404。原来的处理是**只降级不显示**，
于是这两条 id 永远留在本地，每次进页面都白打两次请求。

### 改法

`renderMyReports()` 里，把 404 的行挑出来：

- **剔掉**：从 `state.reported` 删掉 + `saveReported()`，计数改成剩下的条数；
- **说一句**：「另有 N 条举报记录已经在库里查不到了……**这不是你的举报被撤销**」——
  悄悄消失比留着更糟，用户会以为举报被撤了；
- **全被剔光时不 `hidden`**，而是显示那句话 + `0 条`，同样是为了不让人以为记录凭空没了。

### ⛔ 一条必须守住的边界：403 不能剔

```
404 = 这条帖在库里查不到（被删/换了数据）→ 处置记录永远不会来了 → 剔
403 = 帖子还在，只是"你不是作者也不是举报人" → 换一个 user 参数就会 403
```

**这两个码长得像，含义正相反。** 把 403 当成"过期"删掉，等于**删掉一条真实存在的举报**。
所以判断条件写死成 `r.err.status === 404`，注释里也写了这一条。

### 实测（CDP，同一个有残留的浏览器 profile）

```

                localStorage: ["p_20261017_0003","p_20261017_0004"] → []
                页面显示：0 条 + 「另有 2 条……已经在库里查不到了」
第 2 次进页面   异常 0、控制台 0、整块隐藏（index 为空，不再发请求）

403 那条（p_20261018_0002，用 u_demo 查 → 实测 HTTP 403）
                rows=1、id 仍在 localStorage、没有那句 stale 说明 → 没被误删 ✓
```
