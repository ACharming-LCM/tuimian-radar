## 怎么跑的（与派单命令的差异，必须说清）

派单写的是 `crawl.py --refresh`。这次**没有**跑它，改为离线重抽：

```
cd D:\tuimian\collector
python tools\backfill_attachment_extract.py            # 预演
python tools\backfill_attachment_extract.py --write    # 落盘
python tools\make_fixtures.py --as-of 2026-10-18
python tests\test_data_contract.py
```

理由：这次改的只有两件事 —— 附件正文怎么拼接、截止日怎么认 —— **完全由磁盘上已有的
字节决定**（`data/raw/files/<sha1(url)>.<ext>` 就是那些附件）。`--refresh` 会去敲 37 所
学校、重新下载数百份 PDF，既慢又会把"规则改动"和"网络波动导致记录增减"混在一起，
反而看不清 `unknown 293 → N` 到底是哪一边造成的。仓库里本来就为此留了
`tools/backfill_field_state.py`，这次沿用同一套回放思路（并复用了它的 `base_body_of`）。

代价也要写明：**本轮没有验证"重新联网抓一遍会得到同样结果"**。下次日更（`--refresh`）
会真正走一遍网络，那时用 `runs/<日期>.json` 复核。

耗时：预演/落盘各约 3–4 分钟（1119 条记录、280+ 份附件全部命中本地缓存，无网络请求）；
fixtures 0.4 秒；数据门禁约 12 秒。

## 改了什么

1. **`pdf.normalize_soft_linebreaks`（新）**：合并 PDF 排版造成的软换行。
   判据：上一行确实有换行、两行都不空、上一行末尾不是句末标点、下一行开头是
   小写字母/数字/中文数字/**汉字**，且不是列表编号（（一）、1.、一、、①）。
   汉字之间不插空格 —— 插了会把「开/放时间」变成「开 放时间」，关键词就再也匹配不上，
   南京骨干那条正是这么漏的。空行视为段落分隔，不合并。
2. **`fields.DEADLINE_TIERS`**：新增 `开放时间` / `申请平台开放` / `开放第N轮报名`
   （N 支持"二/三"这类中文数字）。
3. **`fields.RANGE_GAP`**：区间连接符加全角 `－`。
4. **`fields.TIME_RE`（新）**：比较日期前先抹掉时分（`21:00`、`9：00`、`8时30分`）。
   四川大学博士招生章程原先只取到起始日 11-27，就是被 `8时` 挡断了区间。
5. **`crawl.EXTRACT_VERSION` v5 → v6**：正文与 deadline 都变了，下一轮 diff 应把它归成
   `reparsed`（我们改了代码），而不是"学校改了 655 条公告"。
6. **`crawl.py` 缓存复用加版本闸**：只复用 `extract.version == EXTRACT_VERSION` 的记录，
   否则改了规则在 `--no-refresh` 下永远不生效。

## 精度护栏（本轮新增的第二次修正）

第一版改完，`unknown` 降了 18 条，但复核 59 条变化时发现**一批录取后义务被当成了报名截止**：
南京 5 条「拟录取名单公示及调档」、中大 2 条「推荐免试…体检表」、浙大「新生报到」、
华师「拟录取后续事项」、中科大 2 条「选课须知」、华师「新生入学须知」、南大「党团关系转接及户口迁移」。
这些通知里的日期确实存在，但**对"我还能不能报名"没有意义**，正是派单边界里点名要避免的那一类。

于是补了两道：

- `POST_ADMISSION` 词表扩到 `调档 / 拟录取 / 党团组织关系 / 组织关系 / 户口迁移 / 入学须知 / 新生入学 / 选课`；
- 新增 `POST_ADMISSION_TITLE_RE`：**整篇主题**是录取后事务时（标题命中
  入学须知/新生入学/拟录取/调档/选课/组织关系/户口迁移/报到/注册通知），正文日期一律不计。
  为什么必须看标题：这些通知的日期句往往写得很干净（「系统开放时间拟定于8月14日—8月17日」），
  句子里一个"新生"都没有，只看句子挡不住。

结果：11 条 `found → absent`（撤销），unknown 从 275 回升到 284，但**precision 是对的**。
抽检三条撤销证据：北大「2026 年10 月20 日前完成拟录取名单网上公示」、华师「拟录取后续事项」、
浙大「新生报到工作」——都不是报名截止。

## 顺带修掉的一个真 bug

`common._ascii_url`（新）：四川大学「国优计划」的附件 href 里带中文文件名，
`urllib.request.Request` 只吃 ASCII，于是抛 `InvalidURL`，在 `pdf.enrich` 里表现为
"下载失败"——看起来像对方服务器坏了，其实是**我们没发出去**。
现在把非 URL 安全字符按 UTF-8 百分号转义后再请求，缓存键仍用原始 URL（历史缓存不失效）。
修完这份 xlsx 正常下载并抽出 189 字，`test_pdf.py` 也从红转绿。
