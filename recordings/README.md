## 二、为什么还没录视频

1. **排序今天还会再变一次**（B 的 B18/B19 之后还有一轮）。脚本里所有位置都写成了"按标题认"，
   但录屏是**一次性**的：录完排序一变，画面里的顺序就和脚本对不上了。
2. 这台机器没有可用的录屏工具链（没有 playwright / sharp，也没有 ffmpeg 的屏幕捕获），
   我能做的是**关键帧**（CDP 截图，就是上面这 9 张）和**逐字稿**，视频需要人按脚本走一遍。
3. 演示前要先解决**心跳是红的**这件事（`last_run.ok=false`，06:25 那轮抓取失败的记录还在）。
   那一行在①里是正面素材还是翻车，取决于它刷不刷得绿。
