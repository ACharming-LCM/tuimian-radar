### 1.3 付费墙挪成加演（不在七步里）

### 1.1 画像那一镜降级成可选

需要讲"个性化从哪来"时再插播，或直接在 ② 的「意向学校命中」标签上带一句。

## 2. 必须拍到的三个「硬镜头」

这三屏是**评委最容易追问的地方**，缺一个就会在台上被问住：

### 2.1 三态同屏（⚠️ 换页面了：**去公告列表页拍，别在推送页等**）

一屏里要同时能看到：

```
截止 2026-10-24（还剩 7 天）        ← found
该公告未公布截止日                   ← absent
⚠ 未能读取截止日，请点原文核对 看原文 ↗   ← unknown，**必须带链接**
```

**🔧 这一版必须改拍法。** 2026-10-18 02:20 实测（`u_num_demo`，20 条推送）：

> **found 12 / absent 7 / unknown 1** —— `unknown` 现在有 1 条（B2 换排序后上来了），但位置会变，别指望它固定在那一屏。
> 所以**推送页上拍不出三态同屏那张图**，这不是页面坏了，是那 20 条里真的没有 unknown。

**改在 `notices.html` 拍**，实测整页（1440×2200 一次截全）：

> **found 27 / absent 11 / unknown 12**，`unknown` 的 12 条**全部带「看原文 ↗」**。

> ⛔ **`?source=sample` 也不能拿来补了**：样例 5 条事件命中 3 条，被「同一公告合并」压成 **1 张卡**，
> 横幅照常挂上。旧文档那句「样例里三条恰好各占一态」已经失效。

### 2.2 T-7 提醒（② 推送页第一张卡）

```
T-7　还剩 6 天（2026-10-24 截止），已进入 7 天提醒窗口
```

实测 20 条里**13 条带提醒**（T-7 与 T-3 混合，实测文本是「还剩 6 天 / 还剩 3 天 / 还剩 2 天」这一段）。
这一屏是"推送到底值不值钱"的唯一实证，**真数据就能拍到，不用样例**。

### 2.3 付费墙不挡原文（⑦）

同一屏里同时有「🔒 还有 N 条推送」和「看原文 ↗」，墙下面还写着一行
「原文链接**永远免费**，不订阅也能点」。

## 3. 不能录的东西（录了会反噬）

| 别录 | 原因 |
|---|---|
| **顶部带「演示样例事件」横幅的推送页** | 那说明用的是样例数据。主画面必须无横幅 |
| **论坛页**（除非列表里已经有帖子） | 0 条会显得产品是空的。发一帖再录，或直接跳过 |
| **`u_demo` 身份下的主画面** | 它现在是免费身份但**没有画像**，推送页会落进 `empty_reason=no_profile`。空态可以用它，主画面不行 |
| **`daily.html` 的「过去 N 天」只有 1 天** | 今天是第 1 天，别把一格说成"连续好几天" |
| 任何**页脚写「本地样例」**的屏 | 主画面只能是真接口 |
