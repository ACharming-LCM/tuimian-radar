# 真人试用方案（保研生试用 + 观察）

> **为什么有这个文件**：我们把数据、接口、页面、门禁全立起来了，
> 但**没有任何一个真正要保研的人打开过它**。这是四天里唯一没法靠写代码补上的空洞。
> 一个人只要在旁边看他用五分钟，能发现的东西比我们改一晚上还多。
>
> **谁能用这份文件**：任何一个队友，不需要懂前端。你只需要一个人（最好是真要保研的）+ 一张纸。
> **做不了的部分**：找人和当场观察只能真人做，AI 替不了。这份文件负责让那件事**明天就能开始**。

---

## 0. 怎么用（主试先读这一段）

1. **测试前**：先把第 2 节的「失败线」抄到纸上（或者打印这一页）。
   **一旦开始看人用，就不许改它了** —— 否则你会不知不觉把标准往"我们做到了"的方向挪。
2. **找 3 个人**，越不像我们越好（不同专业、不同年级、用过/没用过类似网站的都行）。
3. 把第 1 节的任务卡给被试，**别说别的**。你坐在他斜后方，闭嘴，拿第 3 节的表记录。
4. 三个人做完，填第 5 节：**哪一条假设被证伪了**。

---

## 1. 给被试的任务卡（可以直接念给他，或打印出来给他）

> 我们做了个网站，想请你用一下。**没有标准答案，你也测不出"错"**，
> 我们就是想看你**真实的反应**——包括"这什么玩意儿"和"这我看不懂"。
> 所以请你**边用边把心里想的说出来**，比如"我在找…""这个我看不懂""哦原来是这样"。
> 你觉得别扭、找不到、不敢信的地方，都是最有用的。

**背景**（照这个设定）：

> 假设你今年要保研。你最想知道两件事：
> **浙大物理学院什么时候截止**，以及**该找哪个老师**。

**任务**（一次给一个，别一次说完；他做不出来就直接进下一个）：

1. **「你用一下这个网站，看看能不能知道它是干什么的。」**
   （不提示、不导航。**心里默数他多久说出这个网站是干嘛的**。）

2. **「假设你要报浙大物理学院的推免，你想知道截止日期。你找找看。」**
   （看他去哪一页找、点了什么、最后有没有找到；找的是不是我们要他看的那处。）

3. **「现在假设你想联系一位老师。你找找看怎么联系。」**
   （看他找不找得到那一路：匹配结果页右栏 → 导师 → 邮箱。）

**做完之后再问三句**（不要中途问）：

- 「你觉得这个分数（指着匹配度）是什么意思？」
- 「你觉得这些数据是从哪来的？」
- 「如果明天就要报名，你敢按这上面的信息安排时间吗？为什么？」

---

## 2. 测试前先定好的「失败线」（**先定，再看**）

**只要被试出现下面任何一条，这次就算"这条没做到"**，不要事后解释成"他其实懂了"。

| # | 失败线（照抄，别改） | 怎么判定 | 对应我们在赌的假设 |
|---|---|---|---|
| F1 | **15 秒内说不出这个网站是干什么的** | 从页面打开开始默数，超时即记 | H1：一屏之内能看出这是个"帮保研的人看信息"的产品 |
| F2 | **找不到"截止日期"在哪** | 三个页面之内没指到截止日相关的信息 | H2：用户会先去公告列表/匹配结果找截止日，且找得到 |
| F3 | **看不懂"匹配度 0.39"是什么意思** | 问完那三句后仍说不出"越高越适合我" | H3：0–1 的分数对非技术用户是自解释的 |
| F4 | **找不到"怎么联系老师"** | 没走到"匹配结果页右栏 → 导师 → 邮箱"这一路 | H4："该找谁"这条路，从首页是可达的 |
| F5 | **问了"这是真的吗 / 数据从哪来的"** | 原话记下来。**问出来就算，不管他信不信** | H5：我们的可信度设计（原文链接、疑似标记、待确认）足以让人先信一步 |

> **F5 单独说一句**：这条**很可能被触发**，而且触发不一定是坏事——
> 用户怀疑数据来源是正常反应。我们记它是为了知道：
> **页面上的那些"诚实设计"（看原文、疑似、截止日待确认）到底有没有起到作用。**
> 如果他被问了、而且页面答得上来，那是我们赢了；如果页面答不上来，那就是真问题。

## 3. 给观察者的记录表（一行一个观察，照这个填）

**规则：只记事实，不写评价。** 不要写"交互很流畅"，要写"他点了三次'导师'才进去"。
**表情一定要记**——皱眉、笑、往后靠、来回滚，都比嘴上说的准。

| 时间 | 他说的话（原话） | 他在做什么 / 卡在哪 | 表情/动作 | 我的猜测（先别下结论） |
|---|---|---|---|---|
| 0:12 | 「这是…找学校的？」 | 停在那句 slogan 上不动 | 皱眉 | 没看懂定位 |
| 0:40 | 「截止日期在哪啊」 | 来回点"导师"和"公告" | 有点烦 | 导航名字没帮上忙 |
| 1:05 | 「哦，这里写了还剩 8 天」 | 指到匹配卡片的截止标签 | 点头 | ✅ |
| 2:20 | 「这个 0.39 是啥意思」 | 指着分数 | 困惑 | 缺一句话解释 |
| … | | | | |

**重点盯三件事**（比记满整张表更重要）：

1. **他找不到的东西**（在哪儿卡住超过 10 秒）。
2. **他不用导航、直接乱点的地方** —— 说明那个入口不在他预想的位置。
3. **他皱眉头但没说话的地方** —— 事后追问「刚才这里你在想什么」。

**别做的事**：
- ❌ 别说「你点这边」（一提示，这次观察就废了）
- ❌ 别问「你觉得好不好」（他一定会说好）
- ❌ 别解释产品逻辑（想解释的地方，就是你该记下来的地方）

## 4. 三个人的安排

| 谁 | 为什么选他 | 什么时候 | 状态 |
|---|---|---|---|
| 被试 1 | 真在准备保研的人（同专业最好） | | [ ] |
| 被试 2 | 不同专业 / 不同学校的保研人 | | [ ] |
| 被试 3 | 不准备保研的人（看他能不能听懂） | | [ ] |

> 三个人**分开做**，不要坐在一起（会互相提示）。
> 每个被试控制在 **10 分钟以内** —— 超过 10 分钟还没走完，本身就是一个数据点。

| F4 找不到联系老师 | | | | |

### 5.2 哪一条假设被证伪了（**这一页是这一晚最值钱的产出**）

写清楚三件事：

1. **被证伪的是哪条假设**（H1–H5 中的哪一条）。
2. **具体是哪句话/哪个动作让你这么判断的**（引用记录表里的原话）。
3. **我们打算怎么改**（能当天改的就当天改，改不了的写进「诚实的边界」那页 PPT）。

```
被证伪的假设：
证据（原话/动作）：
结论：
打算怎么改：
```

> **三条假设全被推翻也没关系** —— 那说明我们终于知道了真实用户在哪里。
> 比带着"我们自己觉得挺好"上答辩台安全得多。

### 5.3 意外收获

被试做了什么我们完全没预料到的事？（比如他根本不看匹配，只想按学校翻列表。）
这一类往往比失败线更有用。

## 6. 诚实说明：测试时会有哪些"不是产品问题"的干扰

写在这里，免得观察者把环境问题记成产品问题：

- **数据只覆盖部分学校**（现在 8 所左右）。被试如果上来就找自己的目标学校、而那个学校没抓到，
  要分清：这是**覆盖问题**，不是**页面问题**。F2 的判定只在有数据的学校上算数。
- **论坛现在 0 条帖子**。被试打开论坛会觉得空 —— 这是预期的（演示时会现场发一条）。
- **截止日期只有约 31% 的公告抽得到**。如果他抱怨"好多都没写截止日期"，
  **记下来**，但要知道这是我们写在"诚实的边界"里的既有短板。
- **服务要自己起**（`python run.py`）。不要在测试中途排查服务问题，重新起一遍继续。

## 7. 一句话

**这套东西的价值不在"我们做了个文档"，而在"明天真的有人坐在旁边看一个保研生用五分钟"。**
没有那五分钟，我们所有的门禁、断言、走查，都只是在验证"我们自己没写错"。
