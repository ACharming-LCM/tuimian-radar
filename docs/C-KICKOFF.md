# C 启动包（前端）

> **你不等 B。** 从第一分钟起你就能写完整前端，因为接口样例已经生成好了。
> 读这一页 + `contracts/fixtures/*.json` 就够开工。

## 你的目标（一句话）

让人**一屏之内看出三件事**：今天有什么新的、哪个快截止了、哪个适合我。

## 你能改哪里

**只有 `web/`。** `collector/` 是 A 的，`server/` 是 B 的，都不要碰。

## 第一小时（不用等任何人）

```bash
git clone <仓库地址> tuimian && cd tuimian
git config user.name "C-前端"
git config user.email "c@tuimian.local"

# 关键技巧：从**仓库根目录**起静态服务，这样 web/ 和 contracts/ 同时可访问
python -m http.server 5173
# 浏览器打开 http://127.0.0.1:5173/web/
```

然后建 `web/index.html`，用这一句就能拿到真数据：

```js
const r = await fetch('/contracts/fixtures/notices.list.json');  // 形状 = 真接口
const { total, items } = await r.json();
```

**`contracts/fixtures/` 里四个文件就是全部接口的样例**：

| 文件 | 对应接口 | 里面是真的数据 |
|---|---|---|
| `notices.list.json` | `GET /api/notices` | 74 条里的 50 条 |
| `notices.detail.json` | `GET /api/notices/{id}` | 单条完整记录，含正文 |
| `match.response.json` | `POST /api/match` | 真实的匹配结果，带上理由和提醒 |
| `me.response.json` | `GET /api/me` | 订阅状态 + 套餐（做付费墙用） |

**把 base url 抽成一个常量**（例如 `const API = '/contracts/fixtures'`）。
B 上线后你只改这一行就切到真接口。

## 页面优先级（**按这个顺序做，做完一个再下一个**）

| 顺序 | 页面 | 为什么排这个位置 |
|---|---|---|
| 1 | **匹配结果页** | 这是整个产品的价值主张。评委会问"输入背景能得出什么"，这一页就是答案 |
| 2 | 公告列表页 | 卡片：学校 · 院系 · 标题 · 发布时间 · 截止日 · 标签 |
| 3 | 公告详情页 | 正文 + 附件下载 + "看原文"按钮 |
| 4 | 今日更新页 | 读 `data/out/changes.md` 的三类：新增 / 有变化 / 本轮未抓到 |
| 5 | 付费墙页 | 用 `me.response.json`，**模拟支付**，不要接真通道 |

**做不完五个不如做好两个。** 演示时最值钱的是第 1 和第 4 页。

## 三个必须照做的地方（这些是差异化，不是装饰）

1. **`deadline` 为 `null` 时显示「截止日待确认」，并且旁边带上提示。**
   实测只有 **26%** 的记录抽到了截止日。
   **绝对不要留空白，也不要猜一个日期填上去** —— 用户会照着你猜的日期安排时间。
2. **`extract.confidence < 0.5` 的记录要标「疑似」，低置信的排后面。**
3. **匹配页必须显示 `warnings`。** 比如"公告提到「托福」，若你没有相应材料请先确认是否影响申请"。
   用户最怕的不是不知道有哪些项目，是**点进去才发现自己不符合条件**。
   这一条是整个产品最难被抄的部分。

## 视觉上别踩的坑

- 数据里 `title` 可能很长（有些公告标题 50+ 字），卡片要能截断且可展开。
- `majors`/`tags` 是数组，长度不定，别写死宽度。
- 有 `attachments` 的记录要能一眼看出"有附件"（附件里常常才是正文）。
- 排序默认按发布时间倒序；**但匹配页按匹配分倒序**。

## 最后一步：5 分钟的演示脚本

D4 之前把这条路径录成脚本，现场照着走，不要即兴：

1. 打开**今日更新页** → "昨天到今天我抓了 N 所学校，新增 3 条、1 条被改过"
2. 打开**匹配结果页** → 现场填一个真实背景（就用你们自己的）→ 出结果
3. 点开第一条 → 展开理由和提醒 → 点"看原文"跳到学校官网
4. 点"生成套磁信" → 展示 `citations` 能指回原文
5. 打开**付费墙** → 说清"哪些免费、哪些订阅"，并主动讲"我们没接真实支付，因为学生拿不到商户号"

**第 5 步主动交代，比被评委问出来强。**
