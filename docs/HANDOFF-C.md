## 6. 五条硬规矩

1. **永远不要只报总量**：一律「入库 2751 → 默认展示 2583（拒收 168 junk）→ 今日可用 721」。

4. **「不知道」不许说成「没有」**：`absent`（正文确实没写）=「该公告未公布截止日」；
   `unknown`（我们没读到）=「未能读取截止日，请点原文核对」。两句对用户是相反的意思。
5. **「现在还能报」只有一个算式**：`topic=apply ∩ 非 junk ∩ 未过期`（`absent/unknown` 算"不知道"，不算过期）。
