## 1. 问题

- **一句话**：保研要的信息散在几十个院系网站上，截止日藏在附件里，导师方向要一个个翻。
- **页上放**：三行短句 + 一个大数字（`50+` 院系网站 / `附件` 里才写截止日 / `一个个翻` 导师方向）。别放段落。
- **素材**：不用截图。可以放一张"某学院官网截图 + 红圈标出 PDF 附件"。
- **待确认**：`50+` 这个数字用哪个口径（候选站点 50 个？公网可达 37 个？）—— **建议用能站住的**：
  「候选 50 个站点，公网可达 37 个」（README 里有实测）。

## 2. 我们做什么

- **一句话**：抓 → 结构化 → 按你的背景匹配 → 再往下钻到导师。
- **页上放**：一条横向管道图，四个方框：`抓取` → `结构化字段` → `背景匹配` → `导师层`。
  每框下面一行小字（`8 所学校` / `正文 100%` / `每条给理由` / `2 所院系`）。
- **素材**：无（自己画四个框）。
- **待确认**：要不要在这页就提"可解释"（每条匹配都给理由）—— 我建议提，这是差异化。

## 8. 数据

- **一句话**：我们抓到的、以及我们**没**抓到的。
- **页上放**（实测值，2026-10-17）：

  | 指标 | 值 |
  |---|---|
  | 公告 | **72** 条 |
  | 学校 | **8** 所 |
  | 正文非空 | **100%** |
  | 导师 | **67** 人 / **2** 所院系 |
  | 导师研究方向覆盖 | **100%** |
  | 截止日抽取率 | **32%** |

- ★ **必须如实标一句**：**「导师层目前只跑通 2 所院系，不是各校都覆盖」**（A 特别要求）。
  同样建议给公告覆盖也加一句口径：**「网站可达 74%，栏目发现精度 64%」**。
- **待确认**：数字取哪个时点（演示前会再变）。**建议页面角落标"截至 X 月 X 日"**。

## 9. 商业模式

- **一句话**：免费够用，订阅买的是**持续服务**（不是把公开信息藏起来）。
- **页上放**：两栏对照（免费：公告列表不限量 / 每天 3 条详情；订阅 ¥29/月：截止日提醒、套磁信、论坛全文、变更推送）。
- **素材**：`_c-shots/08-pricing.png`（和演示第 5 步同一张，看情况二选一）。
- **待确认**：定价是团队决定；另外要不要提"推免季畅读 ¥99/5 个月"（现在页面上有）。

## 10. 诚实的边界 ★（A 说这页看着像减分，其实是加分项）

- **一句话**：**一个知道自己哪里不行的团队，比一个说"全都行"的团队可信。**
- **页上放**（每条都写"已知 + 打算怎么办"）：

  | 边界 | 现状 | 怎么办 |
  |---|---|---|
  | 截止日抽取 | 32%（很多学校把日期放在附件或图片里） | 接模型兜底；**现在宁可不显示，也不猜一个** |
  | 导师层 | 2 所院系跑通（实测 6 所里 1~2 所能用） | 每所站点结构不同，需要人工核对栏目 |
  | 套磁信 | **模板生成，还没接模型** | 机制（引文逐条回链）已经建好，接模型是替换正文 |
  | 论坛 | 还没有真实帖子 | 演示现场发一条 |
  | 覆盖 | 网站可达 74%，SPA / 公众号 / WAF 抓不到 | 锁定 10 所能稳定抓的，把召回做满 |

- **待确认**：这页的**措辞**要团队定 —— 我建议**主动讲**，而不是等评委问。
  演示脚本第 5 步"主动交代没接真实支付"就是同一个思路。

## 11. 下一步

- **一句话**：这一版证明了机制，下一步是把它铺开。
- **页上放**（骨架，待团队填）：
  - 抓取：从 8 所 → 锁定的 10 所稳定覆盖；院系与导师层继续扩
  - 模型：接入 LLM，做字段兜底 + 套磁信正文（**引文回链机制不变**）
  - 部署：现在跑在校内（部分站点的 DNS 解析到内网），要部署到教育网
  - 合规：论坛的审核队列与通知—删除流程已经有了，这是能上线的底线
- **待确认**：要不要放"我们要多少钱/找什么人"—— 取决于比赛性质。
